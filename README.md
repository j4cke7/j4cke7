## ใช้งานยังไง

1. ดาวน์โหลด ZIP ของเกมที่ต้องการ แล้วแตกไฟล์ทั้งหมด
2. ดับเบิลคลิก `Install.cmd` ไม่ต้องลงโปรแกรมเพิ่ม
3. เปิดเกมแล้วเลือกภาษาตามหน้าของเกมนั้น

ถอนม็อดด้วย `Uninstall.cmd` เจอปัญหาหรือคำแปลผิด แจ้งได้ที่ Issues ในหน้าของเกมนั้น
